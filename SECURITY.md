# Política de Segurança - PortfolioHUB

## Versões Suportadas
Atualmente, apenas a branch principal (`main`) recebe atualizações de segurança e correções de bugs.

## Como relatar uma vulnerabilidade
Caso encontre alguma falha de segurança nos scripts Python ou na plataforma web, por favor, não crie uma "Issue" pública. Envie um e-mail diretamente para: **orlandocesar.2006nunes@gmail.com**.

## Práticas de Código Seguro
1. **Tratamento de Exceções:** Todos os scripts Python (`.py`) possuem blocos `try/except` para prevenir quebras do sistema por entradas inválidas.
2. **Prevenção de Vazamento:** É estritamente proibido realizar o commit de senhas, chaves de API ou tokens de acesso neste repositório.
3. **Auditoria Gemini:** A arquitetura lógica e os tratamentos de erro foram revisados utilizando a inteligência artificial Google Gemini.
